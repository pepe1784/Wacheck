## 🎮 CÓMO USAR - 2 FORMAS SIMPLES

### FORMA 1: Menú Visual (Para ti - MÁS FÁCIL) ⭐

1. **En tu escritorio**, doble click en: **"Wacheck Tools"**

2. Verás un menú como este:
   ```
   [1] Iniciar servidor local (puerto 8080)
   [2] Iniciar servidor local (puerto 3000)
   [3] Abrir en navegador
   [4] Ver mi IP local
   [5] Crear nuevo proyecto Cordova
   [6] Agregar plataforma Android
   [7] Compilar APK (debug)
   [8] Compilar APK (release)
   [9] Abrir proyecto en Android Studio
   ...
   ```

3. **Escribe el número** y presiona Enter

### FORMA 2: Comandos Simples (Opcional)

En la terminal de VS Code:

```powershell
# Ver IP local
Get-MyIP

# Iniciar servidor
Start-Server

# Compilar APK
Build-APK

# Verificar instalaciones
Test-DevTools
```

## 🚀 EJEMPLOS PRÁCTICOS

### Ejemplo 1: Ver tu juego en el celular

**Método del menú:**
1. Doble click en "Wacheck Tools" (escritorio)
2. Opción [1] - Iniciar servidor
3. Toma tu celular
4. Abre Chrome
5. Ve a la IP que muestra (ej: `http://192.168.0.23:8080`)

**Método terminal:**
```powershell
cd C:\xampp\htdocs\Wacheck\Wacheck
Start-Server
```

### Ejemplo 2: Compilar tu APK (cuando instales Android Studio)

**Método del menú:**
1. Doble click en "Wacheck Tools"

3. Esperar
4. Se abrirá la carpeta con tu APK

**Método terminal:**
```powershell
cd C:\xampp\htdocs\Wacheck\Wacheck\apk\WacheckAPK
```

### Ejemplo 3: Abrir proyecto en Android Studio

**Método del menú:**

**Método terminal:**
```powershell
cd C:\xampp\htdocs\Wacheck\Wacheck\apk\WacheckAPK

```
