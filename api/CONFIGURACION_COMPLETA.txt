🔧 CÓMO PROBAR EN XAMPP (LOCAL):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣ Asegúrate que $useProduction = false (línea 18 de user_handler_HYBRID.php)
   ✅ YA ESTÁ CONFIGURADO ASÍ POR DEFECTO

2️⃣ Crea la base de datos en phpMyAdmin:
   - Abre http://localhost/phpmyadmin
   - Crea nueva base de datos: wacheck_db
   - La tabla se crea automáticamente

3️⃣ Prueba la API:
   - Ejecuta: api/PROBAR_API.bat
   - O visita: http://localhost/Wacheck/api/user_handler_HYBRID.php?action=ping
   - Deberías ver: {"status":"ok","source":"web-apk-hybrid"}

4️⃣ Prueba desde el juego:
   - Abre index.html en el navegador
   - Intenta registrar un usuario
   - Inicia sesión
   - Juega y verifica que se guarde el progreso

⚠️ IMPORTANTE - DIFERENCIAS CON LA API ANTERIOR:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

API ANTERIOR (api_old/user_handler.php):
❌ Requiere comentar/descomentar código para cambiar entorno
❌ Usa MySQLi (menos seguro)
❌ Nombres de columna inconsistentes
❌ No maneja bien CORS

API HYBRID (user_handler_HYBRID.php):
✅ Un simple switch para cambiar entorno ($useProduction)
✅ Usa PDO (más seguro)
✅ Nombres de columna consistentes
✅ CORS automático para APK
✅ Compatible con ambos sistemas (web + APK)
✅ Mapeo automático de nombres (snake_case ↔ camelCase)
